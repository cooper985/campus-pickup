### 来源保护与兼容

`handledBatchSources → evaluateAutoBatch` 被正常完成和重启恢复共同调用，避免两套规则继续漂移。`handledSources` 与 records/imports 放在原有同键 envelope 中保存，不影响 outcomes 的展示统计，也不把“已处理”误当成“永久禁止再识别”。

新字段是可选的，旧 v1 批次可读，不做数据迁移；旧融合收据会在下一次检查点前从仍存在的 images/outcomes 回填。升级前已经消失、也未保留收据的来源关系无法凭空重建。

**回退限制：** 旧 V3.0 的严格字段白名单不认识 `handledSources`，直接回滚旧源码可能进入存储保护状态，不会自动删除数据。回退时应保留兼容读取逻辑；不要通过清空存储解决。
